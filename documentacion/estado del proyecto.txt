1. QUE ES
----------------------------------------------------------------
App de descargas de musica/video para uso personal:
- Escritorio (Electron, Windows) con motor yt-dlp + FFmpeg
- Telefono: misma UI como PWA instalable o APK (Capacitor),
  conectandose por WiFi a la PC (token de emparejamiento)
- Fuentes: YouTube (audio/video), Spotify (resuelto via
  busqueda en YouTube) y flacdownloader.com (visor embebido
  manual para lossless)

----------------------------------------------------------------
2. ARQUITECTURA (ver cambio 3 para el detalle)
----------------------------------------------------------------
src/core/     Logica pura sin Electron (AppCore + servicios)
src/server/   REST + SSE con node:http (standalone disponible)
src/desktop/  Shell Electron (IPC minimo, visor FLAC nativo)
src/web/      UI unica (escritorio + navegador + Android)
android/      Proyecto Capacitor
documentacion/ ESTA CARPETA (cambios numerados + este archivo)

Flujo: UI -> HTTP/SSE -> server -> core -> yt-dlp/FFmpeg

5. DECISIONES FIJADAS (no revertir sin pensar)
----------------------------------------------------------------
- Nada de automatizar la API de flacdownloader.com (etica +
  estabilidad). El usuario navega manual; la app organiza.
- FLAC no aparece como formato en Buscar: las fuentes de Buscar
  son lossy; FLAC real solo via pestaña FLAC.
- La cola de descargas vive SOLO en la pestaña Descargas (sin
  panel lateral en Buscar, sin saltos automaticos de pestaña).
- applyMediaMetadata: spawn directo de ffmpeg (fluent-ffmpeg
  rompe titulos con espacios).
- Visor FLAC: WebContentsView del main process con triple
  seguro al ocultar (Electron 28). No volver a <webview>.
- disable-gpu-compositing activo por la iGPU HD 4400 (frames
  fantasma). Reevaluar si se actualiza Electron.
- SW cache-first: subir CACHE_NAME (actual v9) en cada cambio
  de UI, o los clientes PWA no actualizan.
- Breakpoints: <768 movil / 768-1099 tabs superiores / >=1100
  sidebar + tabla de resultados.
- Saltos de linea LF en todo el repo (.gitattributes).
