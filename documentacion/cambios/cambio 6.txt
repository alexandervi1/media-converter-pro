------------------------------------------------------------
1. OBJETIVO
------------------------------------------------------------
Permitir descargas lossless (FLAC) usando flacdownloader.com
como fuente, SIN automatizar nada: el usuario navega y descarga
manualmente en una ventana integrada, y la app ordena cada
archivo que baja hacia <descargas>/flac/.

DECISION ETICA/TECNICA: no se automatiza la API del sitio ni se
elude su anti-bot (Cloudflare Turnstile). La app es ventana +
organizador de carpeta. Integrar la API privada del sitio
(credenciales en pool de Qobuz/Tidal) fue descartado.

3. ARQUITECTURA ACTUAL DEL VISOR (importante - hubo 3 iteraciones)
------------------------------------------------------------
EVOLUCION: ventana aparte -> <webview> embebido -> WebContentsView
del main process (ACTUAL). El <webview> se descarto: al
destruirlo su capa nativa quedaba pintada sobre otras pestañas.

FUNCIONAMIENTO ACTUAL:
- Al entrar a FLAC, el renderer envia los limites de
  #flac-webview-wrap por IPC (flac:embed true+bounds) y el main
  acopla una WebContentsView (particion persist:flac) con
  addChildView + setBounds + setVisible(true).
- Al salir (switchTab != flac), flac:embed false -> removeChildView
  + setVisible(false) + setBounds 0x0 (triple seguro: Electron 28
  puede dejar la capa nativa componiendose con removeChildView solo).
- Al abrir el cajon de ajustes sobre FLAC, la vista se oculta
  (el cajon es DOM y la vista nativa flota encima).
- window resize -> el renderer reenvia limites.
- El estado del sitio se conserva entre visitas (vista cacheada
  en main, cookies en la particion persistente).
- webviewTag se desactivo en la ventana principal.

DESCARGAS: session.fromPartition('persist:flac') con will-download
-> guarda a temp -> core.organizeIncomingFile -> mueve a
<downloadFolder>/flac/ con nombre sanitizado y unico -> SSE
flac-update. La ventana aparte usa la MISMA particion.
