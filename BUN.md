# Uso con Bun

## Instalar Bun

En Windows:

```powershell
winget install Oven-sh.Bun
```

O visita: https://bun.sh/

## Instalar dependencias

```bash
bun install
```

## Ejecutar la app

```bash
bun run start
```

## Otros comandos

```bash
bun run dev
bun run build
bun run build:win
bun run lint
```
